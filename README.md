# FashioNexus-Secure - Secured Fashion Retail Platform

This project demonstrates the identification and remediation of critical security vulnerabilities in the FashioNexus fashion retail platform. Originally vulnerable to broken access control and CSRF attacks, this secured version implements enterprise-level security measures including authentication, role-based access control, and CSRF protection.
